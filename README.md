# Тихо — стоматология / Портфолио-концепт

Русскоязычный лендинг вымышленной московской клиники. Полноэкранный интерьер, подход, раскрывающиеся направления, первый визит, FAQ и рабочая демо-форма.

## Запуск

Нужен Node.js. Зависимостей нет: `npm run dev`. Адрес по умолчанию http://127.0.0.1:4173. Если порт занят, PowerShell: `$env:PORT='4175'`, затем `npm run dev`.
Можно открыть index.html напрямую: изображения и шрифты локальные.

## Проверка и сборка

`npm run check` — проверка синтаксиса. `npm run build` — сборка в dist. Публиковать содержимое dist. Автоматического деплоя нет.

## Демонстрационная форма

Имя, телефон, направление, врач, дата и время — рабочие поля с валидацией. Используйте только вымышленные данные. Кнопка «Заполнить тестовым примером» подставляет Анна и +7 (000) 000-00-00. После подтверждения демо-режима форма показывает результат и очищается. Ввод не передаётся на сервер и не сохраняется в cookies, localStorage или sessionStorage. Внешних скриптов, аналитики, API и удалённых шрифтов нет.

Telegram, WhatsApp и почта открывают поясняющее окно. Реальных аккаунтов, адреса клиники и телефона нет. hello@tiho.example — демонстрационный адрес. Реальная запись не создаётся. Сайт не оказывает медицинских услуг.

## Файлы

- index.html, styles.css, script.js — страница, адаптивность и взаимодействия.
- assets — WebP, локальные Onest 300/400 и лицензия OFL.
- design/concepts — три исходных визуальных концепта.
- design/DESIGN.md — дизайн-система, уточнения и результаты проверки.
- scripts — сервер и сборка без зависимостей.
- AI-RULES.md — исходные правила, сохранены без изменений.
- design/README-original.md — сохранённое описание предыдущего проекта.

Фотографии созданы встроенным Imagegen и не изображают реальные помещения. Исходники сохранены в design. Выбрано пользователем направление №3.

## Интерактив и расписание

«Знакомый снаружи. Интересный внутри.» — интерактив по нажатию на сам зуб. Первый клик показывает эмаль и дентин в разрезе без пульпы, второй открывает пульпу, третий возвращает целый зуб. Три изображения сохраняют один ракурс и масштаб. На модели всегда видна кнопка с названием следующего действия; рядом с изображением указаны номер слоя и факт о нём. Работает мышью, касанием, Enter и пробелом. При reduced-motion смена состояний происходит без анимации.

Иллюстрации assets/tooth-whole.webp, assets/tooth-enamel-dentin.webp и assets/tooth-cutaway.webp созданы встроенным Imagegen с одинаковым ракурсом. На промежуточной иллюстрации видны белая эмаль и жёлтый дентин, но не пульпа. PNG-оригиналы находятся в design.

Список направлений — светлая панель с выделением текущего пункта. Доступны стрелки, Home/End, Enter, Escape и Tab. При выборе направления из секции услуг значение переносится в форму.

После выбора направления появляется поле врача с отдельным списком из двух или трёх вымышленных специалистов для каждого направления. После выбора врача появляется кнопка выбора даты. Календарь открывается по нажатию на неё и показывает текущий месяц и два следующих. Прошедшие даты отключены, полностью занятые зачёркнуты и подписаны. После выбора даты календарь закрывается, а свободные и занятые часы появляются ниже. Это вымышленное локальное расписание, не связанное с клиникой или сервером. При смене направления врач, дата и время сбрасываются. Подтверждение содержит услугу, врача, дату и время. Реальное бронирование не создаётся. Без JavaScript кнопка отправки отключена.
