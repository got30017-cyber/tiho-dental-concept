# Тихо — дизайн и ограничения

Выбранное пользователем направление №3: полноэкранная архитектурная фотография, текст снизу слева. AI-RULES v3 active. Статический HTML/CSS/JS без зависимостей.

## Система

Onest 300 / 400, локальные TTF и OFL. Белый #FFFFFF, графит #24332F, зелёный #355C49. Второстепенный текст через opacity. Радиусы 0 / 999px. Шаги 8, 16, 24, 40, 64, 96. Единая кривая cubic-bezier(.22,1,.36,1). Контейнеры открытые, линии отделяют строки. Стрелки и плюс — SVG, 1.5px, currentColor. Без теней и градиентов.

## Осознанные уточнения

Пользователь попросил рабочие поля заявки с демо-маркировкой: меняем строку «без личных данных» на «без отправки данных». Поля имя, телефон и направление, проверка формата, подтверждение использования вымышленных данных. Никакой отправки, аналитики, cookies или storage. Очищаем поля после успеха. Реальные контакты отсутствуют, кнопки контактов открывают объяснение демо-режима. Email использует .example.

Текст услуг нейтральный, без гарантий и лечебных рекомендаций. Не переносим из концепта медицинское обещание «предотвращает кариес», утверждение «в любом возрасте» и предложение написать в реальную клинику. Не используем надпись «спокойствие тоже лечит». Логотип — простое слово, набранное Onest, без отдельного графического знака. На мобильных фотография сохраняется на весь экран, нижние секции складываются в колонку.

Единственное акцентное взаимодействие — список направлений: раскрытие информации и перенос выбранного направления в заявку. Остальное — обычные формы, FAQ и навигация. Stagger и blur применяются деликатно, reduced-motion отключает движение.

## Изображения

Созданы встроенным Imagegen, а не API/CLI. Фотографии вымышленные, не реальные помещения клиники. Промпты: архитектурный интерьер стоматологии с тёмной стеной из ореха, светлой стойкой справа и стеклянным кабинетом; отдельный кабинет с креслом, дневным светом и теми же материалами. Концепты включают всю страницу, а фотографии созданы отдельными проходами без элементов интерфейса.

## Итоговая проверка

Проверено через встроенный Browser/IAB, без fallback. Viewport 1536×1024 (размер hero-концепта) и 390×844. Концепт и сохранённый итоговый скриншот просмотрены через view_image; остальные секции проверены браузерными снимками. В IAB сохранённые снимки сжимаются, поэтому мелкая типографика дополнительно проверялась на живой странице.

Обычные SVG-стрелки вместо иконок брендов в контактах. Мобильный кроп смещён на тёмную стену для читаемости без оверлея. Отдельно проверены мобильное меню, мобильная отправка, FAQ, пояснение Telegram. Отсутствуют переполнение по горизонтали, битые якоря, незагруженные картинки и ошибки консоли. Никакой передачи формы или хранилища в script.js нет. npm run check и npm run build выполнены.

Существенных нерешённых визуальных дефектов не обнаружено. Реализация соответствует выбранному направлению с перечисленными редакторскими уточнениями.

## Дополнение по запросу пользователя

Интерактивная модель зуба работает по нажатию на само изображение. Нативная кнопка переключает три статичных иллюстрации в одном ракурсе: целый зуб → эмаль и дентин в разрезе без пульпы → разрез с пульпой → целый зуб. Постоянная зелёная кнопка на модели сообщает следующее действие, а подписи через aria-live дают полезный факт о текущем слое. Иллюстрации условные, не предназначены для диагностики. На мобильных пояснение располагается под изображением, на десктопе — слева.

В демо-форме врач появляется только после выбора направления; у каждого направления собственный список вымышленных врачей. Расписание появляется после выбора врача. Календарь закрыт до нажатия «Выбрать дату» и закрывается после выбора дня. Занятые даты и часы помечены и недоступны. При смене направления зависимые поля сбрасываются. Подтверждение показывает направление, врача, дату и время, не создавая реальной записи.
