# ГРАНЬ

Русскоязычный сайт-концепт премиального детейлинг-ателье. Антихром, полировка, интерактивное сравнение и демонстрационная запись на консультацию.

## Запуск

Требуется Node.js. Устанавливать зависимости не нужно.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Другой порт: переменная окружения PORT. Можно также открыть index.html напрямую: шрифты и фотографии локальные.

## Файлы

- index.html — страница с русскими текстами и семантической разметкой.
- styles.css — дизайн-токены, адаптивность, анимация.
- script.js — мобильное меню, ползунок, выбор услуги, валидация и демо-подтверждение.
- assets — шесть сгенерированных фотографий, локальные шрифты и favicon.
- design/concepts — четыре исходных визуальных концепта.
- design/DESIGN.md — решения и уточнения относительно концептов.
- .frontend-design/gran/2026-09-19-gran.html — автономный экран правок, открывается как локальный файл.

## Экран правок Frontend Design

Он собран из этой страницы, без шаблонного контента. Справа основной тёмный вариант, слева дополнительная светлая подача для сравнения. Стрелка разворачивает выбранный вариант. Параметры слева меняют CSS-токены. Текст редактируется прямо в макете. «Комментировать» включает выбор элемента. «Экспорт правок» собирает Markdown, который можно отправить в Codex.

Изменения в экране правок не переписывают исходники автоматически. Экспортируйте их перед закрытием страницы. Это интерфейс обсуждения дизайна, рабочие взаимодействия формы проверяйте на основном сайте.

## Проверки

`npm run check` — проверка синтаксиса. scripts/verify.cjs и scripts/verify-review.cjs — браузерные проверки на текущем рабочем месте, используют установленный Chrome и Playwright из окружения Codex. При переносе проекта путь к Playwright в этих скриптах нужно заменить на локальную установку.

## Подготовка к публикации

`npm run check` проверяет синтаксис, `npm run build` собирает отдельную папку `dist` без зависимостей. Публиковать нужно только `dist`, а не корень проекта. Служебные документы, локальный сервер, экран правок и неиспользуемые картинки в неё не включаются. `.gitignore` исключает локальные артефакты и секреты из репозитория. Workflow `.github/workflows/pages.yml` собирает `dist` на GitHub и публикует её в Pages после push в `main`; в настройках репозитория нужно выбрать Pages → Source → GitHub Actions.

Перед публичным запуском: проверить журналы/обработку технических данных хостинга, права на изображения и видимые автомобильные марки. Лицензия двух используемых шрифтов включена в `assets/fonts/OFL.txt`. У формы есть предупреждение об использовании вымышленных данных. Отсутствие отправки формы не означает автоматически отсутствия обработки технических данных хостингом.

Бесплатный кандидат для самостоятельного демо без реальных сделок — GitHub Pages; решение зависит от согласия владельца публиковать исходники и условий платформы. Для реального бизнеса или сбора заявок архитектуру и документы нужно пересмотреть. Доступность из российских сетей и HTTPS проверяются после деплоя, заранее гарантий нет.

### Поведение демо-формы

Форма проверяет имя, телефон, модель, услугу и подтверждение демонстрационного режима. Введённые данные не отправляются с сайта и не записываются в хранилище приложения; они используются только для вывода результата в текущей вкладке. Выбор времени показывает предпочтение для демонстрации, не бронирует реальный слот. Изображения до/после — сгенерированная визуализация, не реальные клиентские кейсы. Для действующего бизнеса нужно подключить обработчик заявок и заменить концептуальные сведения реальными.
